# 500 самостоятельных задач Python

По 100 задач D, C, B, A и S. Каждая строка ниже — самостоятельный контракт, а не вариант оформления ответа другой задачи. Примеры и скрытые проверки находятся в tasks.json.

- **Новые дружбы и крупнейшая группа** (`py_oddity_a_dynamic_friend_groups`). data=[n,рёбра], n≥0. Добавляй неориентированные дружбы по порядку. После каждой верни размер крупнейшей компоненты; повторы и петли допустимы.

- **Ближайший такой же маяк** (`py_oddity_a_nearest_equal_grid`). data — прямоугольная матрица целых. Для каждой клетки найди минимальное манхэттенское расстояние до другой клетки с тем же значением; если её нет, -1.
- **Маршрут с минимальным перепадом** (`py_oddity_a_minimum_grid_effort`). data — непустая прямоугольная матрица целых высот. Стоимость пути по сторонам — максимальный модуль разницы соседних высот. Верни минимальную стоимость от верхнего левого до нижнего правого.
- **Повороты важнее длины** (`py_oddity_a_minimum_turn_grid`). data — непустая прямоугольная матрица 0/1, 1 — стена. Старт и финиш — углы. Ход по стороне, первый шаг без поворота. Верни минимум поворотов либо -1 при невозможности/стене в углу.
- **Полюса с равенством и запретом** (`py_oddity_a_bipartite_constraints`). data=[n,условия], условие [a,b,p] требует color[a] XOR color[b]==p, p=0/1. Верни bool совместимости всех условий.
- **Связность отсутствующих связей** (`py_oddity_a_graph_complement_components`). data=[n,рёбра] — простой неориентированный граф. В дополнительном графе соединены разные вершины без исходного ребра. Верни размеры его компонент по возрастанию.
- **Самый узкий грузовой проход** (`py_oddity_a_bottleneck_reach`). data=[n,рёбра,s,t], n≥1, неориентированные рёбра [u,v,ёмкость], ёмкость≥0. Выбери путь, максимизирующий минимальную ёмкость ребра. Верни ёмкость, для s=t — 0, без пути -1.

- **Обратные стрелки** (`py_oddity_a_edge_reversal_path`). data=[n,рёбра,s,t], n≥1, ориентированные пары. Разрешено развернуть любые рёбра. Найди минимальное число разворотов, необходимых для появления пути s→t; если даже без направлений пути нет, -1.

## Ранг S

- **Водопровод с обратными остатками** (`py_oddity_s_capacity_flow`). data=[n,рёбра], n≥2, ориентированное ребро [u,v,ёмкость≥0]. Источник 0, сток n-1. Верни максимальный поток, параллельные ёмкости складываются.

- **Билеты используются все** (`py_oddity_s_euler_tickets`). data — список ориентированных билетов [из,в] со строковыми названиями. Старт A. Верни лексикографически минимальный маршрут, использующий каждый билет ровно раз, либо None. Пустые билеты дают [A].

Строй канонически: обход Эйлера вершин (n-1)-битных слов из нулевой, исходящие биты сначала 0, затем 1; биты записывай при возврате, переверни, допиши префикс из n-1 нулей слева.
