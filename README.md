# Anime Code Adventures LMS

> **Version**: 3.0.0  
> **Type**: Gamified Local Learning Management System  
> **Architecture**: FastAPI + SQLite Backend | HTML/CSS/JS Clients<br>
> **Accessibility**: ориентир — WCAG 2.2 AA; проверка всего продукта ещё требуется

---

## 🎮 Overview

**Code Adventures** — гейммифицированная LMS для обучения программированию. Превращает стандартные задачи в RPG-квесты с XP, уровнями и tier-системой сложности.

### Ключевые особенности

| Feature | Description |
|---------|-------------|
| **Zero Config** | Клиенты автоматически ищут сервер в локальной сети |
| **Client-Side Execution** | Python (Pyodide) и JS выполняются в браузере |
| **Secure Auth** | bcrypt пароли + JWT токены с 24h expiration |
| **Rate Limiting** | Защита от брутфорса (5 попыток/минуту) |
| **22 Achievements** | Система достижений с XP бонусами и редкостью |
| **Admin Panel** | Отдельный интерфейс для учителя |
| **Доступность** | Контрастная ночная палитра, видимый фокус, навигация с клавиатуры |

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
cd /home/qarrooak/Documents/PANDORA
pip install -r requirements.txt
```

### 2. Запуск сервера (Учитель)
```bash
python3 main.py
```

При запуске сервер покажет:
```
═══════════════════════════════════════════════════════════
  ⚔️  ANIME CODE ADVENTURES - SENSEI NODE v2.0
═══════════════════════════════════════════════════════════

  📡  Server:  http://192.168.X.X:8000
  🔑  Admin:   admin / admin123

  📋  Tell students to enter IP: 192.168.X.X
```

### 3. Вход в Admin Panel (Учитель)
1. Открыть `admin.html` в браузере
2. Ввести `admin` / `admin123`
3. Создать аккаунты для учеников

### 4. Подключение учеников
1. Раздать файл `index.html`
2. Ученики открывают его в браузере
3. Вводят логин/пароль созданные учителем
4. (Опционально) Вводят IP сервера если автоскан не сработал

## 🎯 Tier-система квестов

Звёзды за каждый уникальный подтверждённый квест: **S — 4, A — 3, B — 2, C/D — 1**.
Недельный рейтинг и статистика гильдий применяют эту шкалу и к ранее выполненным
квестам. Повторное решение не добавляет звёзд; XP и количество задач считаются отдельно.

| Tier | Сложность | XP |
|------|-----------|-----|
| **D** | Beginner | 10-15 |
| **C** | Basic | 30-40 |
| **B** | Intermediate | 50-60 |
| **A** | Advanced | 70-80 |

## 🖥️ Admin Panel v2.0

### Новые секции
| Секция | Описание |
|--------|----------|
| **📜 История** | Просмотр выполненных заданий с кодом, пересмотр XP |
| **📈 Прогресс** | Chart.js график XP по времени (один/все ученики) |
| **🎯 Приоритеты** | Распределение заданий по категориям (%) |
| **🏅 Награды** | Выдача кастомных наград с иконками |

### Улучшенный Review
- Оценка 0-10 с preview XP (`XP = max_xp × score/10`)
- Скачивание `.sb3` файлов напрямую
- Feedback видимый ученику

### Загрузка Scratch

Лимит `.sb3` по умолчанию — **100 МБ**. Переменная `PANDORA_MAX_UPLOAD_MB`
задаёт положительное целое число мегабайт для обычной, быстрой и экзаменационной
загрузки. Интерфейс получает актуальное значение из `GET /api/scratch/upload-config`.
Для multipart-запросов сервер дополнительно допускает 1 МБ служебных полей;
сам файл остаётся ограничен указанным размером. Общий лимит остальных запросов
(`PANDORA_MAX_REQUEST_BODY_BYTES`, по умолчанию 1 МБ) сохраняется.

## ♿ Доступность и дизайн

В профиле ученика, в разделе **«Оформление»**, доступны **новая** и **классическая** темы. Выбор автоматически сохраняется в базе для каждого аккаунта и применяется после входа, включая AlexType. По умолчанию используется новая тема. Классическая тема возвращает прежнее оформление; недельный рейтинг, MVP, титулы, страйк и телеметрия работают в обеих темах.

Клиент ученика использует общую ночную палитру для заданий, рейтинга и AlexType. Стили и управление фокусом основного клиента находятся в `static/pandora-ui.css` и `static/pandora-ui.js`; при переносе проекта на сервер нужна и папка `static/`.

- Контраст основных текстовых цветов и кнопок рассчитан по WCAG; цель — уровень 2.2 AA.
- У диалогов есть доступные имена, удержание фокуса и возврат к вызывающему элементу.
- Из редактора можно выйти по `Shift+Tab` или `Esc`, затем `Tab`; обычный `Tab` добавляет отступ.
- Основные действия имеют область нажатия от 44 px, учтён режим уменьшенной анимации.

Это не подтверждение соответствия всех экранов WCAG. Палитра, критерии проверки и предложения по развитию описаны в [документе о дизайне и геймификации](docs/DESIGN_AND_GAMIFICATION.md).

## ⚠️ Технические заметки

1. **CORS**: `allow_origins=["*"]` для работы с `file://`
2. **SQLite**: База `academy.db` создается автоматически
3. **Pyodide**: Загружается с CDN (нужен интернет при первом запуске)
4. **Сессии**: Хранятся в БД, token в localStorage клиента

### Таблицы БД v2.0
| Таблица | Назначение |
|---------|------------|
| `users` | Пользователи (username, xp, level) |
| `completed_tasks` | Выполненные задания + solution + xp_earned |
| `submissions` | Scratch на проверку + score |
| `user_priorities` | Приоритеты обучения по категориям |
| `rewards` | Награды выданные админом |
| `xp_log` | Лог всех изменений XP (для графиков) |
| `user_stats` | Статистика + avatar_data |
